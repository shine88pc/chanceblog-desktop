# 플랫폼별로 하는 것·하지 않는 것

> 근거: 2026-10-29 약관·정책 조사(`chanceblog` 의 `docs/analysis/2026-10-29_tistory-naver-draft-upload.md`)와 이슈 #83 판단. 약관은 자주 바뀌므로 분기마다 다시 확인한다(다음: 2027-01).

| 플랫폼 | 하는 것 | 하지 않는 것 |
|---|---|---|
| **GitHub Pages**(Chance) | **기존 `chanceblog` 로컬 저장소를 연결**해 그 안에 Markdown·Front Matter 글과 이미지 생성(Chance 글 형식), 이미지 경로 변환, 로컬 미리보기, 변경 파일 목록 확인, 커밋 메시지 자동 생성, **승인 뒤**(항상 최신 `main` 을 먼저 가져온 뒤) commit/push → **기존 자동 배포(`pages.yml`)** 가 배포, 배포 상태 조회, 발행 주소 저장, 중복 slug 방지, 실패 시 로그와 재시도. 현재 자동 발행 동작은 먼저 시험으로 고정하고 어댑터로 감싼다 | 승인 없는 push, 봇이 쓰는 `main` 과 충돌하는 낡은 사본에서의 push(항상 최신 main 에서 시작) |
| **Google Blogger**(영문·한글) | 공식 API 로 **초안 저장**(기본값 Draft), 기존 초안 수정, 라벨 매핑, 초안 관리자 페이지 열기, Post ID 저장, OAuth 재인증·토큰 만료 안내 | **자동 공개 발행**(기본 제공 안 함, 고급 설정에서도 잠금) |
| **네이버 블로그 A·B** | 프로필별 제목·본문·태그 변환, 짧은 문단 구성, 이미지 위치 표시, 이미지 폴더 생성, HTML 미리보기, 제목·본문·태그 복사, 글쓰기 페이지 열기, 발행 전 체크리스트, 발행 주소 입력·상태 저장, **두 블로그 간 제목·첫 문단·본문·이미지·태그·발행일 유사도 비교와 경고** | **자동 로그인·자동 발행**, 댓글·공감·이웃 자동화, 로그인 쿠키·비공식 내부 API, 탐지 회피, 같은 원고를 그대로 복제 |
| **티스토리** | **제외·격리**(D-01). 공식 글쓰기 API 가 2024-02 에 종료돼 안정적인 연동 수단이 없다 | 기본 화면·배포 파이프라인·시험에 넣지 않는다. 비공식 방법은 정식 기능에 포함하지 않는다. 향후 공식 수단이 생기면 새 결정으로 재검토 |

## 공통

- 모든 글은 내보내기 전에 사람이 미리보기에서 **승인**한다. AI 가 쓴 글에는 AI 활용 고지를 붙인다(프로필의 고지문).
- 네이버·티스토리·Blogger 계정의 비밀번호·쿠키·세션은 저장·처리하지 않는다(승인된 D4·G-S7).
- 두 네이버 블로그는 **블로그 표시명·URL·주제·대상 독자·말투·카테고리 매핑·기본 태그·금지 표현·대표 이미지 규격·글 길이·발행 주기·발행 이력·재사용 정책**을 각자 독립 관리한다. 유사도가 기준을 넘으면 경고하고 운영자가 명시적으로 승인해야 `READY_TO_COPY` 가 된다.
- 네이버 AI 활용 표기: 이미지·영상을 AI 로 만들거나 고쳤다면 표기(권장), 글은 기존 표기 규칙을 따른다.
