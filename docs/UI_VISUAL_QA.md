# 화면 시각 검수 — 검증 환경·사진·점검 결과 (PySide6, 창을 띄우지 않음)

> 화면 배율은 **지원 제한이 아니라 검증 범위**다([`UI_DESIGN_SPEC.md`](UI_DESIGN_SPEC.md) §6). 검수는 `scripts/ui_capture.py` 가 **창을 화면에 띄우지 않고**(`QT_QPA_PLATFORM=offscreen`) 사진을 찍고 같은 환경에서 글자 잘림·누르는 칸·가로 스크롤을 점검한다(홈·상태 화면과 설정 화면 — P4a). **이 PC 는 원격 화면(1912×914, 100%)이고 윈도 배율 같은 시스템 설정은 바꾸지 않는다** — 그래서 배율 사진은 Qt 자체의 High DPI 경로를 시험하는 환경 변수(`QT_SCALE_FACTOR`)와 창 크기 지정으로 만든 **'배율 흉내'** 이고, 실제 윈도 125·150% 렌더·한글 입력기·화면 읽기 프로그램·개인 PC 확인은 운영자 PC 검증으로 남는다(§6). **UI-C0 부터는 앱 화면 사진과 따로, 공통 부품 모음(`--gallery` — 개발용)도 같은 방식으로 찍고 점검한다(§7).**

## 1. 검증 환경

| 구분 | 화면 크기/배율 | 창의 논리 크기 | 만든 방법 | 사진(아래 §2) |
|---|---|---|---|---|
| **필수** | 1366×768 / 100% | 1366×768 | 배율 변수 없음 | 홈·여섯 상태 |
| **필수** | 1920×1080 / 100% | 1920×1080 | 배율 변수 없음 | 홈 |
| **필수** | 1920×1080 / **125%**(배율 흉내) | 1536×864 | `QT_SCALE_FACTOR=1.25` | 홈·서랍·대화상자·툴팁·토스트 |
| 조건부 | 1920×1080 / **150%**(배율 흉내) | 1280×720 | `QT_SCALE_FACTOR=1.5` | 홈(핵심 기능을 쓸 수 있는지만) |

**UI-C0 의 부품 모음은 위 네 환경에 1366×768 / 125%(논리 1093×614, `QT_SCALE_FACTOR=1.25`)를 더한 다섯 환경에서 찍는다(§7).** 배율 변수는 프로세스를 시작할 때 정해야 하므로 환경마다 자식 프로세스로 돌린다(앱 코드에는 배율 값이 없고 시험이 그것을 확인한다). 사진의 물리 크기는 화면 크기와 같다(125% 에서 논리 1536×864 → 1920×1080). 화면 없는 환경은 운영체제 글꼴을 몰라서 사진·점검 도구만 윈도가 알려 준 시스템 글꼴(`SystemParametersInfo` 의 메시지 글꼴 — 이 PC 는 '맑은 고딕')을 대신 건넨다 — 앱 코드는 늘 `QFontDatabase.systemFont()` 를 쓴다(창을 만들지 않고 진짜 윈도 플랫폼 플러그인으로 읽어 본 이 PC 의 값: 일반 `GeneralFont`=맑은 고딕 9pt·고정폭 `FixedFont`=Courier New 9pt, 화면 1600×900·배율 1.0 — 점검 도구의 대체 글꼴과 같다). 툴팁은 별도의 작은 창이라 창 사진에 안 찍히므로 배지 바로 아래의 실제 자리에 겹쳐 그린다(화면 없는 환경의 가짜 화면 800×800 이 툴팁을 구석으로 밀어내기 때문).

## 3. 점검 결과 (`python scripts/ui_capture.py <폴더> --check` — 환경마다 홈·여섯 상태·서랍·대화상자·툴팁·토스트)

| 점검 | 1366×768/100 | 1920×1080/100 | 1920×1080/125 | 1920×1080/150 |
|---|---|---|---|---|
| 글자 잘림(한 줄 글이 칸보다 김·줄바꿈 글이 높이보다 낮음·단추 글자가 단추보다 김) | 0 | 0 | 0 | 0 |
| 누르는 칸 36px 미만인 단추 | 0 | 0 | 0 | 0 |
| 가로 스크롤 | 없음 | 없음 | 없음 | 없음 |
| 서랍·대화상자가 창 안에 들어옴 | 예 | 예 | 예 | 예 |
| 툴팁(411×59)이 글자보다 작지 않음 | 예 | 예 | 예 | 예 |
| 사진의 물리 크기·배율(`devicePixelRatio`) | 1366×768 · 1.0 | 1920×1080 · 1.0 | 1920×1080 · 1.25 | 1920×1080 · 1.5 |

이 표의 값은 UI-C0 이전(옛 토큰)에서 쟀다. **새 토큰으로 다시 잰 값은 §7 의 표 2** 에 있다.

125% 에서 직접 본 것: **텍스트 잘림 없음**(홈 한글 제목·설명·칩·배지·요약 카드·오른쪽 패널), **단추 높이**(큰 주 단추 44·표준 40·작은 단추 누르는 칸 36·아이콘 단추 36·메뉴 44 — 시험이 모두 잼), **배지**(24px 높이, `블로그 A`·`예시 데이터` 글자가 잘리지 않음), **툴팁**(키보드 포커스로 뜨고 글자가 안 잘림, 포커스 링이 배지에 보임), **대화상자**(폭 480 이하·창 안, 제목·본문·단추가 잘리지 않음). 150% 에서는 오른쪽 패널이 본문 아래로 내려가고 행의 지표 칸이 그대로 보인다. 점검 도구가 실제로 잘림을 잡는지는 일부러 칸을 좁힌 부품을 넣어 보는 시험(`ToolsTest`)이 확인한다.

**설정 화면(P4a)의 점검**: 네 환경(1366×768/100·1920×1080/100·125·150) 모두에서 설정 화면 8가지(기본·모두 펼침·읽는 중·빈 화면·오류·일부만·오프라인·실제 어댑터)의 **글자 잘림 0·가로 스크롤 없음·36px 미만 단추 0**(환경마다 점검 18건 = 홈 계열 10 + 설정 8, 문제 0). 최소 창(900×560)은 시험이 잰다 — 모든 가짜 시나리오 10종과 오류·빈 상태에서 가로 스크롤 0·글자 잘림 0, 실제로 생길 수 있는 가장 긴 접이식 머리(칩 셋)도 제목과 겹치지 않는다.

자동 시험(`tests/test_ui_qt.py`·`test_ui_qt_scale.py`·`test_ui_qt_images.py` — PySide6 가 없으면 건너뜀)이 같은 것을 코드로 지킨다: 가로 스크롤 없음(1366·1536·1280·1920·최소 창 900×560), 모든 눌리는 부품의 접근 이름·36px 이상, Tab 한 바퀴, Enter/Space, Esc, 서랍·대화상자 포커스 가두기, 같은 토스트 중복 없음, 내 사진 형식별 로딩.

## 4. 성능 실측 (`python scripts/ui_bench.py` — 이 PC·offscreen·Python 3.12·PySide6 6.12.0)

| 항목 | 값 |
|---|---|
| PySide6·화면 모듈 불러오기(import) | 약 1,080ms |
| `QApplication`(글꼴·스타일시트) | 약 50ms |
| 앱 틀 만들기+보이기 / **첫 화면(후보 5줄까지)** | 약 505ms / **약 1,160ms** |
| 1.2초짜리 불러오기 동안 화면이 멈춘 가장 긴 틈(5ms 타이머) | **작업 스레드 176ms**(끝날 때 화면을 다시 그리는 시간 포함) · **화면 스레드에서 직접 기다리면 1,236ms** |
| 화면 한 번 다시 그리기(페이지 전체를 새로 만듦) | 평균 약 139ms · 최대 약 201ms (만들기 약 36ms + 붙이기 약 45ms + 그리기 약 40ms) |
| 뷰모델 만들기 | 후보 2,000개 13ms · 20,000개 88ms (홈은 5줄만 그린다) |
| 작업 집합 메모리(첫 화면 직후) | 약 61MB |

실제 윈도 창은 offscreen 보다 더 걸릴 수 있다. **알려 둔 한계**: 칩·행을 누를 때마다 페이지 전체를 새로 만들어(약 0.1초) 눌린 직후 한 번 깜빡일 수 있다 — 포커스·스크롤 위치는 지킨다. 바뀐 부분만 고치는 갱신은 화면이 늘어나는 다음 묶음에서 한다.

## 5. 사진 찍는 방법

```text
python scripts/ui_capture.py <저장 폴더> [--env 1366x768@100 --env 1920x1080@125 …] [--check]   # 환경을 안 주면 네 환경 모두
python scripts/ui_image_check.py                                                                 # 내 사진 형식별 로딩표(docs/UI_IMAGES.md)
python scripts/ui_bench.py                                                                       # 성능 실측
python scripts/ui_capture.py <저장 폴더> --env 1366x768@100 --gallery [--check]                  # 공통 부품 모음(개발용, UI-C0) 한 장 — --check 를 같이 주면 사진 없이 점검만
```

모두 창을 띄우지 않는다. 사용자의 클립보드·설정은 건드리지 않는다(가짜 클립보드·가짜 서비스). 폭 1000px 로 줄이는 일은 Pillow 가 있는 환경에서 따로 한다(저장소 의존성에 넣지 않았다).
