# 공통 부품 — 화면은 부품만 쓴다 (PySide6)

> 화면(`ui/qt/screens.py`·`shell.py`)은 Qt 기본 위젯(`QPushButton`·`QLabel`·`QLineEdit`·`QCheckBox` …)을 **직접 만들지 않고** `ui/qt/components.py` 의 부품만 쓴다 — 시험이 소스에서 막는다. 색·크기·글자는 토큰([`UI_DESIGN_SPEC.md`](UI_DESIGN_SPEC.md) §2)에서만 오고, 부품 안에서도 `setStyleSheet` 로 색을 쓰지 않는다(속성 `role`·`kind`·`badge`·`tone`·`card` 만 붙이면 `ui/qt/theme.py` 의 스타일시트가 입힌다).

## 1. 계층

```text
tokens.py(값) → theme.py(스타일시트·글꼴·SVG 아이콘 엔진) → components.py(부품) → screens.py(화면 조립) → shell.py(앱 틀·서랍·대화상자·토스트·포커스·작업 스레드 연결)
core/text.py(문구) ─┘                                                       ▲ core/app_state.py(뷰모델) 가 만든 딕셔너리를 그리기만 한다
```

## 2. 부품 표

| 부품 | 모양·규칙 | 접근성·키보드 |
|---|---|---|
| `Button(kind, …)` | `primary`(채움)·`secondary`(테두리)·`ghost`(글자)·`danger` 4종. 높이 표준 40, 큰 주 단추(`size="lg"`) 44, 작은 단추(`size="sm"`) 보이는 34·누르는 칸 36. 아이콘은 글자 앞(또는 `RightToLeft` 로 뒤) | 접근 이름=글자(또는 지정), Tab·**Enter·Space**, 포커스 링(채움 단추는 어두운 링 — 단추 종류마다 포커스 전후의 모양·테두리 색을 시험이 잰다), 윈도 기본 포커스 사각형은 `outline: none` 으로 끈다 |
| `IconButton` | 36×36 아이콘만 있는 단추 | **접근 이름+툴팁 필수**, 툴팁은 키보드 포커스에도 보임 |
| `NavButton`·`LinkButton` | 사이드바 메뉴(높이 44, 현재 메뉴 연한 파랑)·글자 링크 | 접근 이름 `○○ 메뉴로 이동` |
| `FilterChip`·`KeywordChip` | 칩(보이는 34·누르는 36)·키워드 칩(24) | 칩은 켜짐 상태가 있는 단추, 접근 이름 `전체 6` |
| `Badge`·`BlogBadge`·`SampleBadge` | 배지(24). 블로그 A·B 는 **색+글자**(`블로그 A`), `예시 데이터` 는 눌러서 설명 대화상자 | 접근 이름=글자, 예시 데이터는 툴팁 |
| `Card`·`SummaryCard` | 카드(테두리+옅은 면). 요약 카드는 아이콘 바탕(`ToneSwatch` 40×40)·숫자에만 색 | 눌리는 카드는 Enter·Space, 접근 이름 `추천 주제 6개` |
| `TopicRow`(목록 행) | 썸네일 자리·제목·한 줄 설명(넘치면 …)·키워드·지표·추세·배지·단추. 행 폭이 800 미만이면 지표 칸을 접음 | 행 자체가 포커스·Enter/Space 로 선택, 접근 이름 `제목, 블로그 A, 작성 우선도 높음`, 단추 이름 `제목 초안 만들기`·`제목 자세히 보기` |
| `QuickAction` | 빠른 작업 한 줄(아이콘·제목·설명) | 포커스·Enter/Space |
| `TextInput`·`Toggle` | 입력(높이 40, 포커스 링 2px)·스위치(44×26, 글자와 함께) | 접근 이름 필수, Space 로 켜고 끔 |
| `Tooltip`(`with_tooltip`) | 마우스 올림 + **키보드(Tab) 포커스에도** 보임(포커스 이벤트가 끝난 다음 차례에 띄움) | 포커스가 빠지면 숨김 |
| `Toast` | 아래 가운데, **3.5초**, 한 번에 하나, **같은 안내는 쌓지 않고 보이는 시간만 늘림**(`core/notify.py` 규칙), 좁은 창에서도 창 안에 | 화면 읽기 프로그램에 알림(Alert) 이벤트 |
| `Skeleton` | 불러오는 중 — 줄 모양 자리 표시(전체 스피너 없음) | 접근 이름 `후보를 불러오는 중` |
| `StateCard`(빈·오류)·`Banner`(일부만·오프라인)·`Disclosure`(진단 정보) | 아이콘+한 줄 원인+다음 행동 단추. 영문 코드는 접어 둔 진단 정보에만(고정폭) | [`UI_STATES.md`](UI_STATES.md) |
| `Drawer` | 오른쪽에서 밀려 나옴(200ms), 폭 420(창의 92% 이하), 안쪽 스크롤, 바깥(막)·Esc·닫기 단추로 닫음 | 열리면 포커스가 닫기 단추로, Tab 은 서랍 안에서만, 닫으면 눌렀던 곳으로 |
| `Dialog` | 가운데, 폭 480(창의 94% 이하), 창 위에 겹침(별도 창 아님), 처음 포커스는 기본 단추 | Esc 로 닫음(서랍보다 먼저), Tab 은 안에서만 |
| `ImagePlaceholder` | 주제 색 그라디언트+아이콘(64 또는 16:9). 깨진 그림 아이콘을 쓰지 않는다 | 접근 이름: 분야를 아는 후보(예시 데이터)는 `생활·집 주제의 이미지 자리 표시. …`, 분야를 모르는 실제 후보는 `이미지 자리 표시. …`(아이콘은 돌려 쓰는 장식이라 분야를 지어내지 않는다) |
| `AttributionRow`(출처 표시) | `Photo by 작가 on Unsplash`(작가=프로필, Unsplash=홈, 둘 다 UTM) + `출처 복사` 단추 | 링크는 Unsplash 의 https 만 연다, 복사하면 `출처 복사됨` ([`UI_IMAGES.md`](UI_IMAGES.md)) |
| `Label`·`ElidedLabel` | 글자 역할(Typography Token) 하나. 줄바꿈 글은 행간 토큰 적용·**HTML 이스케이프**. 고정폭은 `mono=True`. `ElidedLabel` 은 한 줄로 보여 주고 넘치면 …(줄임표)로 줄이며 전체는 툴팁에 있다 — 오른쪽 패널의 블로그 이름(한글 14자쯤부터 카드 밖으로 잘리던 것)과 추천 행의 한 줄 설명에 쓴다 | 긴 이름이 카드 밖으로 안 나감·툴팁에 전체 |
| `FlowLayout`·`chip_row`·`FlowGrid`·`ResponsiveBody` | 칩 줄바꿈·열 수가 바뀌는 격자·본문+오른쪽 패널(옆→아래) | 가로 스크롤 없음 |

## 3. 키보드·포커스 규칙(시험이 지킴)

- Tab 한 바퀴: 메뉴 → 본문의 모든 눌리는 곳 → 위 막대 설정 단추 → 다시 처음. 모든 정거장에 접근 이름이 있고 같은 곳을 두 번 지나지 않는다(스크롤 영역은 Tab 정거장이 아니다 — 포커스가 간 곳이 보이도록 Qt 가 스크롤해 준다).
- 화면이 다시 그려져도(칩·행 선택) 포커스는 `focus_key` 가 같은 위젯으로 돌아온다.
- 서랍·대화상자가 열린 동안 그 밖의 위젯은 Tab 에서 빠지고, 닫으면 원래 포커스 방식으로 복구된다.

## 4. 새 부품을 더할 때

① 색·크기는 `tokens.py` 에 키를 더하고 `theme.py` 스타일시트에서만 쓴다 ② 접근 이름·키보드·포커스 링 ③ `components.py` 에 한 곳으로 ④ 시험(접근 이름·36px·직접 색 없음은 자동으로 훑는다) ⑤ 이 표에 한 줄.

## 5. 하지 않는 것

화면에서 기본 위젯 직접 생성 · 부품 안의 인라인 색 · 글꼴 이름 지정 · 고정 폭·높이(틀의 기준 폭 — 사이드바 210·옆에 둔 오른쪽 패널 280·서랍·대화상자 폭(창 폭에 맞춰 줄임)과 그림 칸·아이콘 단추·행 최소 높이뿐) · 눌러도 아무 일 없는 단추 · 깨진 이미지 아이콘 · 이모지로 아이콘 대신하기.
